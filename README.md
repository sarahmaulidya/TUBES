# Tugas Besar Mata Kuliah Algoritma dan Pemrograman 2 - Kelompok D - Topik J (MindFlow)

MindFlow adalah aplikasi asisten virtual untuk membantu keseimbangan emosional dan efisiensi kerja pengguna. Data utama yang digunakan adalah data catatan suasana hati, daftar tugas harian, dan riwayat percakapan. Pengguna aplikasi adalah mahasiswa, pekerja kantoran, dan individu yang ingin menjaga kesejahteraan mental.
